# Claude Design · Finance 분석 이어쓰기

Finance는 투자 질문을 체크리스트로 점검하고 판단 기록이나 학습 노트로 남겨 복기하는 서비스입니다. 이번 화면은 질문을 편집하다 중단한 사람이 다시 로그인해 이어서 작성하는 흐름입니다. Finance 클릭 프로토타입 한 개를 만들어 주세요. 기존 Finance 분석 진입 화면과 Ask의 버튼, 체크리스트, 타이포와 간격을 재사용합니다. 시각 기준은 Finance FE `design/claude-export/project/프로토타입 v2.dc.html`과 `Ask 결과.dc.html`입니다. 첨부 `reference/`에 원본 HTML 두 개, 공통 스크립트, `AskPage.tsx`를 함께 제공합니다. 현재 Ask의 기본 화면은 예시 결과를 표시합니다.

프로토타입 도구 막대에 **시나리오 선택 / 모바일 390px / 데스크톱 1440px / 초기화**를 둬 주세요. 실제 제품 화면 밖에 배치하고 **향후 동작 시뮬레이션**이라고 표시합니다. 입력과 저장본은 시안 내부 상태로 관리합니다. 화면 이동과 폭 변경에서 상태를 유지하고, 시나리오 선택과 초기화에서만 고정값으로 되돌립니다. 재로그인은 시안의 버튼으로 재현합니다. 충돌 장면에 **다른 탭에서 저장 발생**, 늦은 응답 장면에 **지연된 응답 지금 도착** 버튼을 도구 막대에 둡니다. 두 사건은 버튼을 눌렀을 때 발생합니다.

고정 합성 질문은 “반도체 업종 하락에 어떤 요인이 겹쳤을까?”입니다. 체크 항목은 “대상 시장 확인”과 “자료 기준 시각 확인”입니다. 시작 상태는 첫 항목만 체크이며, 첫 저장 성공 시각은 14:20, 재시도 성공 시각은 14:21입니다. 충돌 시 최신 저장본에 “환율도 같이 볼까?”가 덧붙은 상태를 사용합니다.

| 장면·상태 | 시작 | 행동 | 반응 → 끝 | 390px / 1440px |
|---|---|---|---|---|
| 정상 저장 | 질문과 체크리스트 작성 중 | 임시저장 | 저장 중 → 저장됨 14:20. 다시 편집하면 미저장 표시 | 모바일에서 긴 입력 뒤에도 저장 행동을 찾고, 데스크톱에서 상태를 저장 버튼 옆에서 읽음 |
| 저장 실패 | 질문과 체크를 바꾼 상태 | 임시저장 → 다시 저장 | 첫 요청 실패. 입력·체크를 유지하고 재시도 성공 후 14:21로 갱신 | 두 폭에서 오류와 재시도 버튼을 찾고 키보드로 다시 저장 |
| 재로그인 복원 | 서버 저장을 모사한 초안 한 건 | 로그아웃 → 같은 계정으로 로그인 → 이어쓰기 → 재확인 → 분석 시작 | 질문과 체크가 복구됨. 재확인과 명시적인 시작 후에만 분석 중 표시 | 모바일에서 이어쓰기 버튼과 체크 영역을 읽고, 데스크톱에서도 같은 순서로 완료 |
| 새 분석·교체 | 저장된 초안이 있음 | 새 분석 → 돌아가기 또는 계속 | 돌아가면 기존 초안 유지. 계속하면 새 편집 화면. 기본안 A에서는 새 초안 저장 성공 시 기존 초안을 교체하고 그 시점을 안내 | 두 폭에서 교체 시점과 취소 경로를 확인 |
| 동시 저장 충돌 | 편집본을 연 뒤 다른 탭에서 더 최신본 저장 | 내 편집본 저장 → 최신본 보기 또는 편집 돌아가기 | 충돌을 알리고 내 입력을 현재 시안 세션에 보존. 최신본을 열기 전에 “현재 입력은 이 화면에서 유지돼요. 최신본을 확인한 뒤 내 편집으로 돌아올 수 있어요.”라고 안내. 최신본 확인 후 내 편집으로 복귀 가능 | 모바일에서 두 행동과 설명이 잘리지 않고, 데스크톱에서도 최신본과 편집본이 구별됨 |
| 늦은 분석 결과 | 분석 중 | 질문·체크를 변경하거나 로그아웃 → 이전 응답 도착 | 변경한 화면은 재분석 필요 상태. 로그아웃하면 이전 결과가 표시되지 않음. 동일 입력의 정상 완료 장면도 제공 | 두 폭에서 현재 상태를 텍스트로 확인 |

Product Owner용 **결정 필요** 패널은 제품 UI 밖에 둡니다. 교체는 A(새 초안 저장 성공 시)를 기본으로, B(새 분석 시작을 확인한 직후)를 비교용으로 표시해 주세요. 두 안 모두 미승인 가정입니다. 완료 후 처리도 화면에 영향을 주는 후보만 비교해 주세요. 보존 기간과 삭제 방법은 결정 목록에 남깁니다. 충돌 화면의 기본 경로는 입력 보존과 최신본 확인입니다. 별도 저장함이나 강제 덮어쓰기를 전제로 장면을 만들지 않습니다.

인수 시 각 행을 두 폭에서 끝까지 클릭합니다. 한 장면에서는 입력·체크·저장 시각을 유지한 채 화면 폭을 바꿉니다. 키보드 탭 순서와 포커스 표시, 긴 콘텐츠의 가로 넘침, 색상 없이 구분되는 저장·실패·재분석 문구도 확인합니다.
